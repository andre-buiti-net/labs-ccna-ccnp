Este repositório documenta minha evolução técnica de CCNA para CCNP através de laboratórios práticos, reproduzíveis e organizados.

### 📁 Estrutura do Repositório

| Pasta | Conteúdo |
| :--- | :--- |
| **/CCNA** | Labs fundamentais: VLAN, Trunk, STP, OSPF, EIGRP, NAT, ACL, DHCP |
| **/CCNP** | Labs avançados: OSPF Multi-área, BGP, EtherChannel, HSRP, STP Avançado |
| **/Capita** | Laboratórios organizados por capítulos do material oficial CCNA |

### 🎯 Objetivo Profissional
Busco oportunidade de **Emprego/Estágio em Redes / Infraestrutura / Suporte NOC**, onde eu possa aplicar na prática os conhecimentos de Routing & Switching, Troubleshooting e documentação de redes.

### 🛠️ Tecnologias e Conceitos Praticados
- **Switching:** VLANs, Trunk 802.1Q, STP, RSTP, EtherChannel
- **Routing:** Roteamento Estático, OSPF v2, EIGRP, NAT/PAT
- **Serviços:** DHCP, ACLs Standard/Extended, Syslog
- **Ferramentas:** Cisco Packet Tracer, Wireshark (básico), Git & GitHub

### 🚀 Como Executar os Labs
1. Clone o repositório: `git clone https://github.com/andre-buiti-net/laboratorios-ccna-ccnp.git`
2. Abra o arquivo `.pkt` desejado no Cisco Packet Tracer
3. Siga as instruções dentro de cada pasta
